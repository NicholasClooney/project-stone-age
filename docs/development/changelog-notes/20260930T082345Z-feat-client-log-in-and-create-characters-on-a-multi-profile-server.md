---
subject: "feat(client): log in and create characters on a multi-profile server"
title: "登录画面：选角色、输 PIN、建新角色"
---

- 连到多角色服务器时先出现「登录石器时代」：点自己的角色、输入 PIN 登录，或「创建新角色」（名字加两次 PIN）；新角色进村后先选择外观。服务器上还没有角色时，第一个创建的就是管理员。
- 这台设备会记住登录：刷新网页、断线重连和下次打开都不用再输 PIN。设置 → 角色 → 切换角色 可退出登录回到选择画面，自动战斗和找宠在服务器上继续。
- 不是管理员的角色看不到 设置 → 开发者（GM 调试、性能面板），本机极速模式线程数只能看不能改。
