title: "开放已审核公开走廊的自动任务 B/C 模式"
---
- 自动任务设置中的 B/C 现可用于七条已审核的原公开走廊：B 到下一原入口外侧普通格，C 沿同一原路最多三格分段、每格约两倍节奏；每次更新最多推进一格。原门、保护区及未知公开段仍按 A 原路逐格处理。
- C 每个实际逻辑格进行原遇敌判定，第一次遇敌立即丢弃尾段；普通战继续使用攻击与简洁结算，胜利成功保存后重新规划。
- B 终点与 C 段末等待当前设备的完整位置确认；取消、断线、换机及成功保存后的模式切换会废弃旧尾段或重签回执，不会借旧位置消息续跑。
- 模式设置保存失败保留原执行状态，人工奖励和 Boss 等待不因移动偏好变化失去合法窗口。无设备重启保守恢复 A，保留 B/C 偏好并明确提示重新启动任务后应用。
- B/C 是项目新增赶路功能，移动不授予原任务到达资格；客户端分段呈现由独立 UI 接入验收。
