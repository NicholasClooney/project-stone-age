---
subject: "feat(client): minimize automation windows while they run"
title: "自动练级与自动抓极品可最小化"
---

- 运行中点「最小化」，窗口收起为右下角进度条，显示场次、等级或找宠进度；点「展开」或再次点入口按钮恢复完整窗口。
- 最小化时自动化继续进行，可同时打开宠物、仓库、状态等菜单存取、整理和放生宠物，菜单内容随自动化即时刷新（网页连接服务器时也一样）；角色保持原地，避免误走中断。
- 最小化不会停止自动化；在完整窗口中点关闭或按 Esc 才会停止。切换地图后进度条仍在；本设备记住是否最小化，刷新网页后按此恢复。
- 手柄按 Back 进入 HUD 模式即可选中「展开」。
