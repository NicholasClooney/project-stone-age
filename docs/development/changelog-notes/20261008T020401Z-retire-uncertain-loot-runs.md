title: "刷物不确定时段安全结束并保留原预算"

- 刷物执行归属或保存封印失效时停止当前刷物；待确认记录只限制同角色新的刷物 Start，普通自动任务、手动操作与普通保存不新增限制。
- 冷加载结束旧刷物时段，保留同一步原预算上限、已存用时下界与已结算收益；后续新 run 使用原余额，不重置为满额，未知时长不补计，旧续跑文件不能复活旧 run。
- 只有原写入器证明本次操作在 IO 前失败时，才允许冻结候选和截止点的一次重试；已写但读回不明只读确认，部分写或未知结果不盲写补救。
- 开发验证：56 case 独立组合与状态、持久化、真实远程恢复 UI 回归通过；节拍按原 clock 的独立 raw + 500ms 证明，返回时刻只作诊断。
- 刷物公开能力仍关闭（cap false）；自然 P3 与实际 2760 收到链仍未证明，历史 natural 的 fallback 断言迁移须另行审阅，本修复不开放功能。
