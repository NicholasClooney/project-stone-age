- 自动抓极品新增「运行设置」「排队与保留」页：战斗期间继续搜索、显示战斗、真实战斗培养分别选择；普通筛选和本机极速均支持后台继续搜索。
- 候选队列始终按品种维护、动态淘汰、轮流捕获，不再等待两分钟摸底。相对门槛缺少同种基线时由首个合格候选建立，绝对门槛仍严格执行。
- 「抓到后直接升至120级」改为「捕获后培养至120级」：可选实际练级战斗或按原成长种子快速培养。只抓不练仍先留随身、满员自动存仓并继续。
- 「捕获前预演保留结果」可独立关闭；开启且自动整理开启时，结合已有和排队同种宠物预演共享规则，预计留不下的记为未捕获，避免抓完又放。关闭后照常捕获培养。
- 捕获原因悬停改为简短提示，完整排名和原因点击详情查看；提示背景改为不透明，避免文字叠在列表上。
