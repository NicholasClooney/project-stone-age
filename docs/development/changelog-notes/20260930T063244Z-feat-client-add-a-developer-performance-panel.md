---
subject: "feat(client): add a developer performance panel"
title: "开发者性能面板"
---

- 开发者功能：按 F3（可在设置 → 快捷键修改）或设置 → 开发者 → 性能面板，在右上角叠加显示内存、帧率和网络，每秒刷新两次；战斗中和窗口上面也能开，鼠标可穿过面板（只有按钮可点）。
- 内存：Godot 静态内存（含峰值）、显存、纹理和缓冲；网页版另有 wasm 堆、JS 堆（仅 Chrome）和已挂载 / 本次下载的资源包大小。
- 明细：按用途估算的纹理（战斗图集、骑乘、地图图块、人物、面部、宠物缩略图、界面）、已载入的音乐 / 电台 / 音效，以及大型清单 JSON 的大小。
- 性能与网络：帧时间、绘制调用、对象 / 节点 / 孤立节点数；本机后台的消息数和 tick 耗时，或远程连接的收发速率和延迟。
- 「导出快照」把所有数字连同版本号写成 JSON：桌面版存到 user://perf-snapshots/，网页版下载文件并复制到剪贴板，便于前后对比。
