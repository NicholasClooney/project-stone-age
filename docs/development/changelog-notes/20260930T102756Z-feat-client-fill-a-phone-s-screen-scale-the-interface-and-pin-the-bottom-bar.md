- 设置 → 画面 新增三项，只影响这台设备：「界面大小」拉条（50% 到 300%，松手后生效）；「固定横屏比例」（关掉后画面铺满屏幕，竖屏手机也能用满）；「底栏常驻」（底部 地图 / 状态 / 宠物 / 道具 / 系统 按钮一直显示，不用把鼠标移到底部）。
- 电脑默认保持原来的比例、100%、悬停显示底栏；手机和平板默认铺满屏幕、界面 200%、底栏常驻。界面很大时有些窗口可能放不下，请调小一点。
