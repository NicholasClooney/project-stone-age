---

- 内部准备：收费离开策略接入默认关闭的门；开启后退出或切换不因收费持久收尾失败而阻塞，先撤旧连接和同归属执行权。目标角色打开失败仍保留旧角色。当前未开放自动买票或200/300自动付款，已有非收费与刷物入口保持。
- 内部保障：待重试依据是现有存档记录与实际恢复文件；内存 pending 只保存归属，不充当持久失败日志。混合与非收费残余不会自动执行或被通用恢复写入覆盖，手动存档仍可保存；当前战斗留给玩家手动完成，不代为结算。
- 内部生命周期：结束连接调用只解除本次引用环；自动战斗交接使用弱身份记录，合法一次消费与错误请求拒绝分开，不借用后继权限。
- 验证说明：三套离开/作用域/对象释放测试及二十二套定向回归通过；真实 Accounts/Hub 与手工运行准备、故障 hooks 的范围分列，父 Start dispatch 对照只在候选环境执行，不等于整棵旧版本运行。默认关闭成功 Start 与保存兼容有独立断言。
- 范围限制：收费新增链仍关闭；私有权限不由公开成功字段或回复产生。JSON 存档边界、Session 对旧路径连续三读而非逐读 CAS、无跨文件原子保证保持；未运行全量、注册新套或验证渲染像素。
