---
subject: "feat(server): keep automation settings in the character profile"
title: "自动练级和自动抓极品的设置随角色保存"
---

- DEV → 自动练级、自动抓极品（筛选条件、抓宠设置、各品种属性条件）改过的设置保存在角色存档中，换地图、重启或刷新网页后保留。
- 多台设备同时连接时，一台设备修改后，其他设备已打开的窗口随之更新；正在输入的数字不会被打断。
- 战斗播放速度和窗口最小化只记在本设备，各设备可以不同；简略或完整战斗随角色保存。
- 旧存档按原来的默认值读取。带宠升级仍只在本次运行使用8×、10×经验和简略战斗，不改写保存的设置。
