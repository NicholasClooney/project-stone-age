- 龙洞一楼守护者恢复龙笛委托，四至六楼按原持笛条件遇敌、按原80%掉落三种龙玉。七楼守卫须独自携三玉通过，只验物不扣玉；最终向三龙任选一件原奖励，交三玉与龙笛后完成转生加点项17。
- 任务助手新增原步骤与地点导航。七楼按地图实际连通区域检查，持三玉也不能直接跳过守卫；通过原门后才可导航三龙。助手瞬移属于项目便利，不自动执行任务。
- 龙之枪与龙的魅力之笛按现有武器、护符槽应用原普通属性与等级40限制。龙之铠、龙之衣仍保留原奖励和源说明，躯干槽、治愈／猛毒／复活魔法尚未生效；原敌特殊技能未恢复。
