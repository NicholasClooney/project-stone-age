---
subject: "feat(client): keep only the best N qualifying pets in the find-pet cycle"
title: "找宠流程可以只留最好的N只达标宠物"
---

- 自动抓极品 → 属性条件 新增「达标只保留前N只」：每存入一只达标宠物，就在本轮的达标宠物里排名，只留最好的N只，其余放生。0（默认）全部保留，与以前相同。
- 排序可以自己选：第一、第二、第三依次比较三围合、攻击、防御、敏捷或体力，默认先三围合再攻击；都相同时再按其余属性，最后留先抓到的。
- 只放生本轮存入仓库的达标宠物；收藏的、以前几轮的、手动存入或已取出的宠物都不会动。想一直找并只留最好的几只，把「找到0只后停止」设为0。
- 窗口和最小化进度条会显示现留几只、已放生几只。
