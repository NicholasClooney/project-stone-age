subject: "feat(server): send players on the same map and 一般频道 chat to each other"
title: "局域网：同地图玩家互相可见与一般频道（服务器）"
---

- 一个服务器多个角色（--accounts）时，服务器每 0.15 秒把同一地图上其他在线玩家的名字、等级、外观、骑乘、位置和「战斗中」发给各个设备，只发有变化的部分；换地图、登录、断线重连时重发完整名单，玩家离线或离开地图就从别人那里消失。
- 一般频道：同一地图上的人都能收到；每句最多 60 字，每 5 秒最多 3 句。单人模式和一人一进程的服务器没有变化。
