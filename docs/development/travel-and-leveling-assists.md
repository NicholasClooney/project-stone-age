# 全区域传送、点击瞬移与练级路线

## 玩家入口

- **DEV → 地图导航**：统一地图选择、兴趣点、练级点与Lv.1宠物导航，移除独立传送地点菜单。地图下拉只列村庄、野外与洞窟，不列建筑室内；初始默认DEV传送，仍可切换步行。选择地图仅浏览，点击地图或目标才移动。当前下拉有53个区域，排除94张建筑室内；人在室内仍可看当前地图，只是不把该室内列为可选区域。随机遇敌开关也移入地图导航。
- **DEV → 瞬移模式**：开启后，点击当前场景直接移动到该位置；障碍附近找可站立落点，地图外拒绝。关闭后恢复点击寻路。村民／探险／商店 DEV 快捷键独立直接传送，不再依赖模式开关。
- **DEV → 刷怪传送**：选择任意 Lv.1–120，显示经典练级路线说明与当前原表可用的推荐／备选落点。到达后开启「自动练级」。同一批刷怪点也显示在全地图导航中，支持点击步行／传送。推荐依据是等级匹配，并非实测经验／分钟最高。

## 地图导航分类

「地图导航」将列表分为 **地点／练级点／Lv.1宠物** 三页。地点页保留地图出入口及普通兴趣点；练级点与Lv.1宠物页支持「当前地图／全部地图」范围，避免村内门口与刷怪列表混在一起。沿用地图缩放、平移和步行／DEV传送选择。点击兴趣点圆点（含边缘）会选中标记的准确落点；无标记的空白处仍按普通地图点击处理，避免误入旁边遇敌区域。

本批生成45个物种与地点组合；标签区分固定Lv.1与可能Lv.1（等级区间）。Lv.1宠物地点依据实际敌人记录的等级范围、可捕获标记及普通遇敌权重生成，并验证可用动画、地图碰撞和原表区域优先级；不因某物种一般可捕获就推断所有出生地点都能遇到Lv.1。任务条件、无效概率、缺素材的记录不作为推荐。列表表示该地点**可能遇到**对应Lv.1宠物，随机抽选可能出现其他宠物或等级，不保证每场出现，也不自动捕获。

重新导入地图、遇敌表或动画后，依次运行 `python3 tools/build_training_spots.py` 和 `python3 tools/build_level_one_spots.py`，更新两个已跟踪的地点索引。不要手动补造位置或等级。

## 经典攻略与当前原表

参考新浪2004年[《升级大法》](https://games.sina.com.cn/zhqu/sta/xsxl/sjdf.shtml)：早期村外／柯奥／阿布，中期海底、穿山甲或五兄弟，后期英雄岛。该攻略的英雄岛水雷需要圣石条件，不能直接当成普通遇敌。

当前固定版本原表与该攻略不同：柯奥没有普通遇敌记录；已导入海底通道等级与攻略海主人区不同；本批阿布主要20–30级、五兄弟50–58级、吉鲁部分区域到84级、漆黑85–95级，英雄岛存在普通高等级区域。水雷相关动画亦有缺失。UI保留历史说明，真正可点击的落点只来自当前可运行资料，不捏造怪物或绕过条件遇敌。

## 生成与验证

1. 运行世界导入器与遇敌动画导入器（README的资源路径）。新增地图通过 `DEV_TRAINING_MAPS` 显式选择。
2. `python3 tools/build_training_spots.py` 生成 `client/data/training-spots.json`；本批203个落点。
3. 筛选普通、非事件、非道具条件的有效敌群；剔除缺概率和缺动画区域。
4. 对每个落点验证原碰撞、NPC／出入口排除、最高优先级区域归属。点击传送时再次检查落点及区域ID；不按修改后的配置盲目传送。
5. 所有1–120级均可查询，等级优先匹配后给出四个去重选项。高等级可能推荐较低等级怪，这是现有可用原表的结果，不改怪物等级。

测试：`travel_destinations_test`、`travel_assists_test`、`leveling_routes_test`、`test_build_training_spots.py`、`test_import_world.py`。默认后台无窗口、静音。

## 五人镜像队

DEV「五人镜像队」开启后，下一场战斗复制四名临时人类伙伴，和主角组成五人队。主角先行动；四个分身自动跟随主角选择的目标，目标倒下则选择另一个活着的敌人，无需逐人指挥。分身复制当前外形、武器、等级、出战宠及骑乘宠。出战宠自动跟随主角目标；骑乘使用原版合成动画、属性和伤害分担，坐骑倒下会下骑。每组人宠血量独立。

**经验仍全部归本体及本体的宠物按现有规则结算**：镜像人物和宠物没有经验份额、独立物品栏、存档或成长，不使战利品数量翻倍。分身击杀也让真实出战宠和骑乘宠按正常规则获得经验。经验倍率先作用于战斗奖励，再按既有规则分配。

捕获／逃跑时镜像人物与出战宠防御，避免打死目标；本体倒下仍结束战斗。分身每场重新复制当前状态。完整战斗、地图内简略战斗、自动练级均使用同一个权威实现。无出战宠时不创建镜像出战宠；未骑乘时镜像也步行。配置在下一场复制，战中本体换宠不改变镜像初始阵容。此功能是单人便利，不是联网五人队或原版合击系统。

实现采用 `battle_session.gd` 默认无行为变化的扩展点与独立 `squad_battle_session.gd`，不复制整套回合调度。关闭镜像队时仍用原单人战斗与敏捷顺序。测试覆盖本体先动、目标跟随、反击／死亡、捕获保护、经验和物品不重复、宠物及骑乘宠收益、完整／简略模式接手。

## 便捷加点

状态窗口有剩余点时，右侧显示辅助面板。设置「UP每次分配」可一次加多点（自动限制到剩余点数）；勾选体／腕／耐／速后「剩余点均分到勾选项」消费全部剩余点，余数按体腕耐速顺序分配。不改变已分配点，空选或战斗中拒绝。沿用原版基础属性换算和自动存档。
