# 镜之精灵饰品

在萨姆吉尔道具店购买 **美丽尼亚护身符1**（4800石币），在道具栏双击装备。它使用原版饰品第一格（左上角），与武器分别装备；唯一已装备副本不同时出现在背包，也不可直接卖掉。卸下后可按2400石币出售。

装备提供战斗中的**主动镜之精灵**，不是永久被动反伤。施放消耗本回合人物行动，为目标提供一次直接攻击反射；具体支持的目标以战斗菜单为准。施放消耗原表物品1460的5点气力（MAGIC_MagicDef：气力不足时战斗菜单不能选，见[精灵与气力](../reverse-engineering/magic-and-mp.md)）。它和柯雅拉护身符都是护身符，不能同时装备。原物品的魅力+1也未接入当前属性模型。

原版物品1460、图22018；原参考商店库存不保证包含该物品，本次在萨姆吉尔售卖是单人便利。原始施法100600与防护100610动画从本地资源提取，未绘制替代素材。装备位置依据参考客户端 `system/menu.cpp:8960` 附近 `ItemBuffer[3]` 的(32,68)。

增量导入：

```sh
.tools/asset-venv/bin/python tools/import_mirror.py /path/to/stoneage2.5
./scripts/run.sh --headless --editor --import --quit
```

完整 `tools/import_mvp.py` 也会导入该物品及效果。原版图像保持在忽略目录；跟踪的是导入工具与规则。`mirror_item_ui_test.gd` 验证购买／出售、装备／卸下、原槽位、背包去重及说明文字不遮挡按钮。测试后台静音，布局检查不等同于图形像素核验。
