# 亚姆亚姆送斧与回信

任务模块 `yam-axe` 按实际 `event03.create` 开放卡坦村1400(69,89)亚姆亚姆和霍特尔村1300(18,42)马提。来源 SHA、原分支索引及NPC实例在 `tools/yam_axe_quest_sources.json`；这是锁定的本地服务端快照，不是所有地区官方版本的认证。

等级1可接取：亚姆给2416临时斧 → 马提收斧写END3 → 再与马提交谈领2423回信 → 亚姆收信给2448改良斧并写END5。只有END5是本批转生加成表中的那一项；当前交付不包括转生结算。接取、取消、物品交换、旗标与保存均走原任务解释器及Session事务。

2416可在20级装备，攻9、防-3、敏-3，无耐久损耗；2448可在25级装备，攻35、防-10、敏-10，原耐久2500000。普通 `ITEM=2416` 按原C仅查背包，因此交给马提前须卸下。两者均无魔法、六抗性字段；没有添加魔法系统。原2416丢弃消失、2448不会消失；本项目“丢弃”统一直接删除，尚无地面拾取，界面明确说明该限制。任务物丢失可在原发放者处取消后重接，原取消扣1魅力。

**入口**：任务助手的两个阶段均列出原NPC位置及瞬移/到地图后行走。助手是项目便利，自动执行未开放。城镇地图使用已有导入；原任务无额外固定战、口令或等级入口。

**验证**：`tools/test_yam_axe_quest.py`精确核对原绑定、分支、物品数值和只开放3/5；`yam_axe_equipment_test`覆盖装备等级、数值、UID持久化和穿戴丢弃失败回滚；`yam_axe_quest_test`覆盖真实Session整链、卸斧交付、每次交付保存失败、取消恢复、重复token与两设备WebSocket竞争（端口0）。`yam_axe_ui_test`在真实390×844离屏渲染中实际点击四段助手行走/对白和奖励装备按钮，截图在临时目录逐张查看，不提交。

旧药草、博士、贝壳suite的公共事件集合断言保留历史12项，并独立读取模块注册清单合并、排序后精确比较完整集合；不把意外启用其它事件视作通过。三项旧suite定向通过。完整suite由父会话统一运行。
