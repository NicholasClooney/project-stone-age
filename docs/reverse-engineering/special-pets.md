## 2. 120 级推算

三围合为攻＋防＋敏，不含血量（`client/scripts/pet_stat_filter.gd`）。「满档」指出生四项档位都是 +2，「随机」指和野生 1 级一样随机。

推算方法：`tools/special_pet_projection.py` 用 Python 重写 `client/server/progression.gd` 的出生（`species_actor`）和升级（`grow_pet`），1 级出生，逐级练到 120。每一级按精确分布抽样（10 点的 286 种分法 × 51 个倍率）。以蓝人龙核对：满档均值 616.8，随机均值约 573，与[宠物品质说明](../game-systems/pet-quality.md)一致。下表满档每种 3 万只、随机每种 1 万只，尾部有 ±1 的抽样误差。

```
python3 tools/special_pet_projection.py 92 303 304 --full 30000 --random 10000
```

原版规则要点（`gmsv/char/enemy.c:1039–1075` 出生，`char/char_data.c:1200–1256` 升级，`enemy.c:767` 档次）：倍率档次由**物种名义权重和**决定，和 ≥100 为 4.50 到 5.00，95 到 99 为 4.70 到 5.20，以此类推，**权重越高倍率反而越低**。所以蓝人龙（和 99）的倍率比红暴、机暴（和 ≥100）高，但后者权重大得多，最终仍然更强。

和一只罕见的 624 蓝人龙（攻 292）比：

- **红暴：** 满档均值 651，但攻击约 284，比蓝人龙的 289 到 292 低，多出来的在防和敏。随机资质的红暴也有约 20% 超过 624。
- **机暴：** 满档均值 646，攻约 275，防约 221，攻防兼备。
- **蓝暴：** 约 604，三围合低于满档蓝人龙，血量较高，原版带「一击必杀」。
- **700 以上**（年兽、机豹、金暴、黑乌力王）：明显是 7.x/8.x 的后期数值，不应和 2.5 时代的宠物混比。
- **黑乌力：** 约 608，价值在属性和获取方式，不在数值。

关于花钱：华义运营时期确实有实体卡和点数卡送虚拟宠物，例如 2002 年的「来吉卡」和「恐龙蛋生包」（包里有红暴、蓝暴娃娃，可玩一次虚宠扭蛋）。但**没有找到可靠来源证明上面哪只宠物是直接用钱买的**。「红暴是第一代氪金宠」只见于一篇已失效的新闻标题，列为待证。

## 4. 本项目现状

- **能拿到的：**
  - **红暴：** 在起始伙伴里。开发用地图 500「五十年前波拉岛」（`dev_only`）有 90 到 95 级野生红暴，捕捉后保留原等级。
  - **表中其他宠物：** 只能用 **GM 调试 → 发放宠物**（开发者功能，见 [GM 控制](../development/gm-controls.md)）。按原表出生规则生成 1 级宠物，可选满档，并标记 GM。
- **战斗图：**
  - 表中宠物的战斗图都由 `tools/import_encounter_art.py` 导入（`SPECIAL_PETS`）。
  - 机豹和黑乌力王只在 8.0 资料里有，需要 `setup-original-data.sh --with-8.0`（导入时加 `--extra-source`）。
  - 没有战斗图的模板不能发放。
- **骑乘：**
  - 机暴、红暴、蓝暴在原版骑宠表里，发放后按骑乘规则可以骑（机暴的合成图来自 8.0 资料）。
  - 红暴和蓝暴骑上去是族长装，因为没有任何客户端有普通装的版本。
  - 蓝豹、金暴的骑宠列只有 8.5 客户端有，服务端源码里没有，所以按设计不能骑。
  - 机豹、年兽、黑乌力在原版里就不能骑。
- **没有实现：**
  - 龙王任务（地图 5511 未导入）和猜谜任务。
  - 转生和骑乘证书 NPC。
  - 漆黑洞窟帖拉所伊朵头目战：地图已导入，NPC 战斗没接上。
  - 年兽活动。
  - 宠物说话和变身。
- **遗留代码：** `pet_growth.gd` 里有一个没有对应物种的 `mechanical_rex` 分类。
