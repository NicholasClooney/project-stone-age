# 宠物怎样才算「极品」？

**先比同种、同版本、同培养条件，再看用途；没有跨所有宠物通用的极品数值。** 初生资质、已经长出的能力、未来成长预测是三件事。本项目自动刷宠的「总档+6」是便利筛选预设，不是已证实的原版官方评级。

## 原版玩家看什么

历史玩家通常看Lv.1初始血／攻／防／敏，再观察培养后的成长。例如2001年的[蓝人龙成长记录](https://news.17173.com/z/stoneage/content/2001-6-14/n822_739098.html)用「当前属性减Lv.1属性，再除以升级次数」估计平均成长；低等级波动与取整影响大，初值好不保证之后每级都好。2002年的[养宠经验](https://news.17173.com/z/stoneage/content/2002-4-1/n638_554329.html)列出的蓝人龙、暴龙、金虎成长范围也不同。这些是当年玩家样本，**不是服务器硬上限，也不能直接当成本项目2.5资料的精确门槛**；文章里的满血养宠等推测不作为实现依据。

攻击宠可以偏重攻击，先手宠可以偏重敏捷，坐骑还要考虑骑乘需求。后期版本的[金虎讨论](https://games.sina.com.cn/zhqu/sta/article/2003-04-29/3642.shtml)也反映用途与玩家口径不同；不能把该时期数值倒套到所有历史版本。不要将后续重制游戏的「普通／极品／完美」等级当成原版2.5已有规则。

## 当前实现的三层数据

| 层次 | 含义 | 怎么用 |
| --- | --- | --- |
| 初生资质 | 四项成长权重分别在物种基准上随机−2到+2，之后作为个体成长参数保留 | 比较同种的先天条件；不是面板攻防敏直接加减2 |
| 已实现能力 | 初始随机分配、每次升级的随机成长和取整累积后的当前面板 | 已经长到目标等级时，直接看这一层及实际用途 |
| 未来预估 | 从这只宠物的当前基础值与真实成长权重，估计剩余升级 | 是条件期望与范围，不是读取未来随机结果 |

注意「总档+6」不是「每级总成长6.0」：前者相加的是四项基础成长权重的偏差，后者若用于面板成长，需要明确所加属性及其计量方式，不能直接对照。

原表先保存四项成长权重，再把10个初始点随机分给四项。每级也共享10次分配，且共享一次成长倍率抽样，因此四项不能当成四条独立骰子。

「自动刷极品」以四项权重相对物种基准的差值之和筛选。默认**总档≥+6**：在当前五种等概率出生偏差、四项独立的模型中，占15/625＝2.4%；全+2为1/625＝0.16%。这只是符合先天筛选的条件比例，**不是在地图上遇到、抓到该宠物的概率**，也不保证最适合你的攻击／敏捷分配。

## 为什么自然资质最多+2，怎样谈「前1%」

每项−2到+2是当前参考源码自然出生的取值范围，不是界面为了降低品质而设的限制。提高GM属性可以超过自然面板，但不会因此成为原规则下的「出生+3」；若扩展出生范围，就是改了成长规则，应与原版自然宠分开标识。

Lv.1面板还包含共享的10个随机初始分配点，因此「初始能力优秀」与「成长权重优秀」应分成两个评价轴；四项初始分配彼此牵制，不是每项都能独立拿10点。同样总档的宠物也会因分配偏向不同，适合不同用途。

「超过99%的同类」需要先规定同物种、版本、出生／培养方式、等级及用途评分，再对这个评分在同条件宠物中的联合分布求百分位。平均值和四项各自90%区间都不能直接算出整体99%排名；四项单独的高百分位也不能相乘当成整只宠的排名。如果只按自然四项权重总偏移排序，则总档≥+7恰为5/625＝0.8%，全+2为1/625＝0.16%；这是明确出生模型下的先天总档上尾比例，不是当前面板或战斗表现的百分位。目前没有实现新的百分位品质界面，不能把+6或高于均值直接显示成前1%。

## 成长窗口逐列读

- **本宠预估**：当前个体到目标等级的平均预期；已有随机成长、旧档偏移也计入。
- **约90%范围**：每一项属性各自的近似常见范围，只描述剩余升级随机性；不是四项同时有90%概率落入，也不是宠物排名前90%。接近目标等级时正态近似更粗。
- **同种正常均值**：同种从Lv.1自然培养到目标等级的平均基准，**不是满档、理论最大值或高等级野生捕获基准**。
- **理论单项上限**：悬停中的边界参照。血量最优的随机分配与攻击最优不同，一只宠物不能同时达到四项极限。它不是实用极品门槛。

比较时必须对齐物种、规则版本、等级及自然培养条件；转生、特殊成长、GM改属性或旧档修正不能直接混比。高等级野生宠的初始能力使用原表野生成长系数，不是完整模拟从Lv.1逐级培养，所以不应把它与Lv.1养成均值的差额全解释为资质差。当前预测仍可从捕获后的真实基础值继续估计。

## 这张Lv.120截图说明什么

标题是 **Lv.120→120**，已经没有未来升级：本宠值就是当前值，范围应收敛为同一个数字。

| 属性 | 本宠当前 | 同种正常均值 | 差额 |
| --- | ---: | ---: | ---: |
| 体力 | 1202 | 1130 | +72（约6.4%） |
| 攻击 | 267 | 269 | −2（约0.7%） |
| 防御 | 192 | 179 | +13（约7.3%） |
| 敏捷 | 174 | 162 | +12（约7.4%） |

它的面板体／防／敏高于该均值、攻击接近均值；**不能仅据此认定出生满档、极品百分位或自然培养优秀度**。截图还有GM／旧档提示，需先确认来源。截图拍摄时提示较宽：GM升级走普通成长也会标记，单纯治疗也会标记，旧档即使四项偏移全为0也可能触发。因此提示不等于「这只宠改过属性」。现在全零旧档偏移不再触发警告；DEV→GM调试可清除所选或全队GM标记（全队包含主角与全部真实宠物），只清标记，不恢复任何数值，非零旧档偏移仍提示。手动清除后也不能证明自然培养或历史上从未改过属性。

## 建议的易读界面（提案，尚未实现）

1. 增加同种先天资质卡：显示四项相对物种基准的差值及总档；筛选门槛注明「项目预设」，与用途表现、自然培养来源分开。
2. 达到目标等级后改叫「当前能力对比」，不再称未来预估。
3. 分开显示「先天资质」「已实现能力」「未来预估」，明确同种同等级自然养成基准。
4. 显示各项相对均值的差额；范围标「每项约90%」，把不可同时达到的理论极限留在说明内。
5. 进一步记录改属性、普通升级加速与仅治疗的区别；来源不明时显示「无法做自然品质判断」。全零旧档偏移误报已修正，但完整来源记录仍是提案。
6. 允许按攻宠／敏宠／坐骑用途设置筛选偏好；未建立同种联合分布前，不伪造「超过99%宠物」评分。
