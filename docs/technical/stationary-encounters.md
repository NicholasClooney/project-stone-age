# 游戏助手：原地遇敌

这是本项目便利功能，原版没有此开关。入口是 **游戏助手 → 原地遇敌**，原有列表、网格和手柄入口保持可用。**不遇敌**改为短标题；其含义仍是关闭地图随机遇敌，主动刷怪与剧情战斗不受影响。

## 开启与停止

- 默认关闭，只存在于服务器内存，不进入角色存档或自动恢复文件。载入存档、重启后都要重新开启。
- 成功开启会关闭这一次助手窗口；服务器拒绝时留窗显示原因。启用期间开启别的菜单、关闭助手或断线，迟到回执只会停止模式，不会关闭后来打开的窗口。
- 和“不遇敌”互斥。开启原地遇敌会先成功保存“不遇敌=false”；开启“不遇敌”会停止原地遇敌。
- 当前位置没有普通遇敌区域、区域最大概率为零、处于传送点或尚不支持的事件遇敌区域时，开关禁用并说明。服务器独立复核这些条件；不能靠客户端改按钮绕过。
- 移动、传送、打开阻挡操作的菜单或对白会停止。重新打开游戏助手也停止，不会在助手仍打开时继续遇敌。
- **本次不支持组队**，队长、队员均不能开启；运行期间加入队伍也由服务器停止。自动练级、抓宠、找宠流程和自动任务与它互斥，需要先停止原来的自动功能。开始其他自动操作会停掉原地遇敌。
- 逃跑、死亡、捕获等非 `win` 结果停止。正常胜利后，要等这场战斗结算成功保存、关闭战斗窗口、待结算记录为空并再次确认保存成功，才恢复遇敌。
- 胜利后继续遇敌**不等于自动战斗**。出招仍由玩家或既有战斗设置控制；本功能不新增自动出招、回血、抓宠或奖励规则。

## 节拍与“原率”的确切含义

`server/stationary_encounters.gd` 在 `Backend._process` 中推进。空闲累计 **0.5 秒尝试一个普通步进**，即理想状态每秒两次，单帧最多一次。每次尝试后累计值归零，服务器卡顿不补跑，实际频率只会更低。战斗及结果窗口期间不累计；成功关闭后重置计时，再等待完整的 0.5 秒。

调用现有 `Backend._cmd_field_step`，复用同一角色的 `EncounterCatalog.pressure` 和 `encounter_rng`，没有固定物种或另造随机流。开启和停止不重置 pressure/RNG。步进把 pressure 限制在区域上下界内，与均匀整数 `0..119` 比较，命中条件 `roll < pressure`，所以单次条件概率是 `pressure / 120`，**不是每秒百分率，也不是固定 100% 开战**。未命中增加 pressure，最多到区域上限；命中回到区域下限，再调用现有野怪组和敌人权重抽取。区域上下限沿用当前普通遇敌实现的 `0..100` 限制。

原始依据为 `references/chenmingbiao-stone-age/gmsv/char/char_walk.c:493–559`；既有实现与未覆盖范围见 [普通遇敌审计](../reverse-engineering/ordinary-encounters.md)。沿用当前导入遇敌表，包括已标记的稀有 Lv.1 补充。本改动不增加敌人、地图或权重；缺失数据或素材时停止，不重抽、替换或重新分配概率。

## 网络、菜单与结算边界

- `stationary_encounters {enabled: bool}` 开关；`stationary_pause` 只能停止本角色；`stationary_keepalive` 返回状态，且只有发起传输连接才能刷新运行租约。身份复用传输层已有的 `_quest_connection`，不信任客户端自报设备身份。
- 发起页面每秒最多发一次续租，服务器 **5 秒**未收到发起连接续租即停止；后台标签页被浏览器暂停同样停止。菜单每秒查询可用性，异步请求尚未返回时不叠加状态查询。
- 未命中步进及续租不广播角色快照；只在开启、停止和现有战斗事件时推送。客户端观察模块只通过 `world.link.request` 请求，不访问或修改 backend。菜单状态只能使模式停止，不能授权地图、组队或战斗规则。
- 模块记录自己打开的 `battle_id`；`Backend._after_turn` 仅通知同场战斗的成功保存结果。保存失败显式停机；原子回滚分支先还原角色与 pending，再发送停止通知，避免广播未保存奖励。未结算终局也停止，不会永久挂着“运行中”。
- 不修改、清空或重建 `session._pending`、任务 pending、`party_settlement`、个人结果 slice 或掉落 claims；不代替既有重试与事务流程。组队不支持并不削弱公共结算保护。

## 验证与限制

- `stationary_encounters_test`：真实 Backend，严格布尔、互斥、安全地图、同种子普通步进的 RNG/pressure/敌群等价、限频、真实胜利/逃跑/死亡、同场保存确认、保存失败与关闭失败、移动、只读命令、自动功能与组队冲突、断线租约、不存运行状态。
- `stationary_encounters_ui_test`：隔离 port 0 WebSocket、没有本地 backend 的真实客户端、实际鼠标点击、390×844 与 1280×720、列表/网格/手柄、拒绝留窗、晚回包保护、断线、服务器原率开战与远端真实出招胜利后继续。加 `--visual-review` 可用静音屏外真实渲染保存 PNG；headless 运行只验证逻辑和布局，不能证明像素。
- 相关回归：`helper_grid_test`、`random_encounter_toggle_test`、`battle_settlement_test`、`lan_party_test`。本任务只运行定向套件，全量留给本批统一验证。
