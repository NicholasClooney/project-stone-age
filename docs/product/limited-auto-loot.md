# 限时刷物基础版

任务助手提供“开始限时刷物”，按服务端当前已审核步骤和资格决定能否开始；当前刷物步骤是精灵王宝玉路线所需的 2760。按钮不可用时，先按显示的资格或状态提示处理。不要把金布伊原路自动任务当作刷物入口：该路径仍不自动送往大厅、购票或刷物。

在任务助手打开“自动任务设置”，可设置每步刷物时限：默认 30 分钟，范围 1–180 分钟。保存设置不会自动开始。已有同一步预算不会因停止、再次开始、修改偏好或冷加载而重置为满额；冷加载保留已保存用时下界和已结算收益，不补计未知时长，界面会说明该边界。

点击“开始限时刷物”后等待服务端结果；不要把请求待确认当作可重复点击的成功或失败。使用“停止自动任务 / 导航”停止后续自动推进。若当前场仍需结算，依照“仅结算当前场，不再开始下一场”等实际提示处理；停止不会额外发放物品。

**低血量时自动停下，交给玩家手动接管。** 原保护可能提示“玩家体力达到停机线”。当前战斗仍在进行时会交给完整战斗窗口，显示“自动抓宠／战斗已暂停：…；可手动接手。”请在该窗口手动操作；暂停不是胜利或已结算，补血也不承诺自动恢复刷物。现有单人保护检查先于普通攻击策略，不要以携带回复药推断会自动喝药越过停机线。

## 验证范围

P3 自然采样及真实发布已有证据。三个实际 E1 自然窗口结束后，2760 的自然实际收到、UID 入包及主存档完整读回仍为 **UNPROVEN**；这项不作为本次基础开放的阻断条件，是用户明确选择。原首次未结算 UNCOMPLETE 保留；另一次 E1 前准备失败单独归档、不计自然窗；后两窗真实低血量保护停机、目标未证，不能称自然套 PASS。

测试使用了原 GM120、属性分配、固定宠物成长及 near 准备等明确便利；后续准备至多通过原 use_item 使用已有两瓶基础回复药，满血或无药停止。没有注入自然奖励、搜索种子或降低产品 HP 保护。headless 检查不证明实际渲染像素。原认证、重复请求、停止和冷加载回归保留，不把这次开关变更解释为所有运行条件下的安全保证。

本次自然观察没有发现重复发物、重复扣钱或存档损坏的新证据；这不等于对所有情况作保证。三底线仍是缺陷处置优先项。更多长跑/罕见分支、额外恢复诊断、专用暂停文案和额外稳健性延期，不新增义务确认或 WAL，也不作为本次开放加码门槛。固定 711 并强制掉落的独立受控补验另行进行，必须明确测试便利，不能冒充自然掉落证据。

源码入口：`quest_helper_menu.gd` / `quest_helper_travel.gd`；服务端权威为 Backend 的 `quest_loot_start`；时限规则在 `quest_auto_settings_rules.gd`；原保护与交接在 `automation.gd`、`battle_auto_policy.gd`、`training_helper.gd`。生产启动、停止、费用、奖励与 Session 的既有事务路径保持原样。
